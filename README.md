Wanderlust Travel Blog

A static travel journal built with plain HTML and CSS — no framework, no build step. Featured destinations, recent stories, a short traveler's guide, and a newsletter signup section.

View live demo (add your GitHub Pages link here once deployed)

Features


Responsive layout (desktop, tablet, and mobile breakpoints)
Semantic HTML structure (header, main, section, article, footer)
CSS Grid for page layout, Flexbox for component alignment
CSS custom properties for a consistent, easy-to-edit color and type system
Google Fonts: Fraunces for headings, Inter for body text
Sticky header, smooth scroll navigation, hover states throughout


Tech Stack


HTML5
CSS3 (no preprocessor, no framework)
No JavaScript dependencies

Getting Started

No build tools or installation required.


Clone the repo:


bash   git clone https://github.com/akanjiogoyemi-ship-it/wanderlust-travel-blog.git


Open index.html directly in your browser, or serve it locally with VS Code's Live Server extension for auto-reload while editing.


Deployment

This project is set up to deploy for free with GitHub Pages:


Push the repo to GitHub.
Go to Settings → Pages in the repo.
Under "Branch," select main and / (root), then save.
The site will be live at https://<your-username>.github.io/<repo-name>/ within a minute or two.
